# Weather Forecast & Alert Application - Frontend

React + Vite dashboard for the Weather Forecast & Alert Application backend.

## Features

- City dropdown
- Current weather summary cards
- Rule-based alert badges
- Hourly temperature chart
- 7-day rain forecast chart
- Daily max temperature chart
- CSV report trigger

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

Backend must be running on:

```text
http://127.0.0.1:8000
```

To change backend URL, create `.env`:

```text
VITE_API_BASE=http://127.0.0.1:8000
```
